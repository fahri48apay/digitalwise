STATE

State Kosong & Error

Edge case penting: streak putus, offline, nol lencana, laporan ditolak. Semua pakai warna & ikon (bukan warna saja) untuk aksesibilitas.

Streak Putus
local_fire_department Streak terputus! Mulai lagi hari ini.

Muncul di Beranda ketika pengguna melewatkan satu hari. Tombol "Mulai streak baru" sebagai CTA. Warna error-container untuk urgency tanpa alarm.

Offline
cloud_off Tidak ada koneksi internet

Banner persistent di bawah top bar. Konten yang sudah di-cache tetap bisa diakses. Muncul di semua layar, auto-dismiss saat online.

Nol Lencana
military_tech Belum ada lencana Selesaikan misi dan kuis untuk mengumpulkan lencana pertamamu.

State kosong di Profil (tab Lencana). Ikon besar redup + copy motivasi. Tidak ada CTA — user harus menyelesaikan misi dulu.

Laporan Ditolak
cancel Laporanmu ditolak Konten yang dilaporkan tidak melanggar pedoman. Pelajari cara mengenali konten bermasalah.

Notifikasi di panel Notifikasi. Error-container bg + cancel ikon. Link "Pelajari" membuka materi terkait (recovery path).

psychologyPsikologi Gamifikasi

  • Goal-gradient: XP card menampilkan "150 XP lagi" — progres mendekati target mempercepat usaha.
  • Peak-end rule: naik level dirayakan layar penuh — momen paling diingat saat sesi berakhir.
  • Loss aversion: streak harian memberi alasan kembali tanpa paksaan.
  • Social comparison sehat: baris "Kamu" + catatan bersaing positif di peringkat.

accessibility_newAksesibilitas

  • 48 pasangan warna light+dark lolos WCAG AA (teks 4.5:1, UI 3:1) — terverifikasi skrip.
  • Semua target sentuh minimal 48dp dengan jarak 8dp (M3).
  • Bottom nav memakai aria-current; ikon dekoratif aria-hidden; label form eksplisit.
  • Animasi konfeti & transisi dimatikan otomatis saat prefers-reduced-motion.

edit_noteKeputusan vs Sketsa

  • Pie chart progres diganti progress bars: perbandingan 3 nilai lebih presisi dan ramah buta warna.
  • Ditambah layar reward level-up dan streak — memperkuat loop Belajar–Main–Menang.
  • Sketsa menulis "Raka" peringkat 1 tapi Level 3 — dihaluskan: podium + baris "Kamu" agar konsisten.
  • Persona demo = "Kamu" (Kirana Putri, peringkat #6, 650 XP) — Raka adalah peer di podium #1; sapaan Beranda, layar naik level, dan Profil mengikuti persona ini.
  • Tombol kuis Aman/Tidak Aman memakai outline + warna (bukan warna saja) untuk buta warna.
